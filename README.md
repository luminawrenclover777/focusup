# FocusUp 个人三维进化系统 (PRD v3.1 · iPhone PWA MVP)

> 遵循需求文档 `FocusUp-PRD-v3.1-iPhone-PWA-MVP.md` 严格开发交付。

## 🌟 核心理念与定位
- **成长三维度**：Focus (专注与自控) · Body (身体微活动与力量) · Voice (结构思考与表达)。
- **iPhone 优先的 PWA**：离线优先、单用户、本地 IndexedDB 存储优先、无账号依赖、操作敏捷、诚实反馈。
- **边界明确**：不宣称系统级应用拦截器或后台常驻，不虚假保证锁屏持续执行，完全基于时间戳校准与用户主动选择。

---

## 🛠️ 技术栈
- **框架**：React 18 + TypeScript + Vite
- **本地存储**：IndexedDB + Dexie（全事务支持、流水审计、防重复发奖）
- **UI & 样式**：Tailwind CSS（适配 iOS 刘海/动态岛安全区、底部 Home 指示器）
- **PWA**：`vite-plugin-pwa` + Service Worker 静态资源预缓存离线启动
- **离线音频**：Web Audio API 纯代码离线合成雨声、棕噪音、粉红噪音
- **动效**：Canvas Confetti 庆祝粒子、平滑过渡

---

## 🚀 核心四大模块

### 1. 模块一：久坐唤醒专注仓 (`FocusPod`)
- **倒计时**：15m / 25m / 45m（保底模式额外提供 10m 轻启动）。
- **正向心流计时**：00:00 启动，自主结束。
- **时间戳校准**：进入后台或锁屏不依赖 `setInterval`，回到前台按时间戳与暂停区间精确计算有效时长。
- **离线白噪音**：雨声、棕噪音、粉红噪音无需外部音频文件即可播放与调节音量。
- **久坐唤醒建议**：工位隐蔽微动作（核心收紧、沉肩收下巴等）与离座微活动。
- **结算与奖励**：展示有效时长与暂停时长，确认后 +1 Focus EXP / 有效分钟。

### 2. 模块二：反短视频破局器与 60 秒思考表达 (`ShortVideoInterceptor` & `Voice`)
- **事前截胡**：打开短视频前点击，+10 Focus EXP（每日上限 5 次奖励），按 20 分钟估算潜在节省时间（明确标注“估算值”）。
- **主动止损**：已经点开后主动切断，+15 Focus EXP（每日上限 5 次奖励）。
- **60 秒表达框架**：
  1. `PREP`：结论 → 理由 → 例子/行动
  2. `现象-本质-行动`：表象 → 底层原因 → 自主微行动
  3. `正反合`：直觉观点 → 反面代价 → 综合结论
- **离线导师追问卡**：根据框架随机触发思考追问，支持补充反思或略过，结算 +10 Voice EXP（每日上限 3 次）。

### 3. 模块三：薄肌训练台 (`LeanMuscleStation`)
- **部位肌群**：肩、背、胸、核心、臀腿预设动作库 + 支持自定义动作。
- **训练记录**：组数、次数、单边/总重（支持自重留空）、手感备注。
- **同动作历史对比**：自动提取上次训练表现。
- **个人突破判定**：超越历史最佳容量触发“个人突破”，额外 +10 Body EXP。
- **恢复时间参考**：展示距上次该部位训练小时数（温和提醒，不作绝对医学判断）。
- **基石习惯打卡**：蛋白质摄入 (+5 EXP)、规律睡眠 (+5 EXP)、日常活动步数 (+5 EXP)，支持撤销打卡与冲正。
- **身体指标**：体重、腰围选填历史趋势。

### 4. 模块四：成长看板与娱乐券 (`GrowthDashboard`)
- **三维雷达**：Focus / Body / Voice 独立等级与进度条（每 300 EXP 升 1 级）。
- **12 周活动热力图**：84 天方块基于真实保存行为点亮。
- **娱乐券赏金钱包**：每累计 150 EXP 奖励 1 张 30 分钟娱乐券，单次确认安全核销。
- **本地数据备份与迁移**：
  - 导出 `FocusUp-backup-YYYY-MM-DD.json`
  - 导入前 Schema 校验、版本检验、记录数统计预览
  - 明确提示“将替换当前数据”，全库原子事务安全覆盖。
